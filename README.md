# mangal
for Serg

Зона мангала: мангал, піч під казан і тумба з умивальником на майданчику 3000 × 1500.

| Файл | Що це |
|---|---|
| [zona-mangala.html](zona-mangala.html) | 3D-модель, версія 23: карго на простих роликових напрямних з підшипниками (галочка «Показати механізми»), мангал 650, кришка на мангалі, ящик під мангалом, карго з фальшгабіоном, дверцята під мийкою — відкриваються кліком; карго для шампурів і решітки зліва; шари (відкрити в браузері) |
| [kreslennia-kompleks.html](kreslennia-kompleks.html) | Креслення всього комплексу: план, фасад, розріз, мангал, кришка тумби, габіон + перелік матеріалів |
| [kreslennia-pich.html](kreslennia-pich.html) | Креслення каркаса печі під казан для зварювальника |
| [kreslennia-tumba.html](kreslennia-tumba.html) | Креслення каркаса тумби для зварювальника |
| [materialy.md](materialy.md) | Список матеріалів |
| [spysok-materialiv.xlsx](spysok-materialiv.xlsx) | Той самий список для Excel: закупівля з цінами, прокат, по частинах |
| [kreslennia/](kreslennia) | Окремі види у SVG (відкриваються прямо на GitHub) |
| [tools/](tools) | Скрипти, що генерують креслення і перелік: `python tools/gen_kompleks.py`, `python tools/gen_pich.py`, `python tools/gen_tumba.py` |
| mangal.html | Окрема 3D-модель мангала |
| zona-mangala.glb, .usdz, -iphone.zip | Модель для iPhone — ще версія 12, без нової печі |
